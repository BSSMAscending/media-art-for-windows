# AI 기술 사용에 대한 설명

## 사용된 AI 기술

이 미디어 아트 프로젝트에서는 **TensorFlow.js**와 **BodyPix** 모델을 사용하여 실시간 인체 인식을 구현했습니다.

### TensorFlow.js
- **목적**: 웹 브라우저에서 머신러닝 모델을 실행할 수 있게 해주는 JavaScript 라이브러리
- **버전**: 4.22.0
- **역할**: BodyPix 모델의 실행 환경 제공 및 GPU 가속 지원

### BodyPix 모델
- **목적**: 실시간으로 이미지에서 사람을 인식하고 분할(segmentation)하는 AI 모델
- **버전**: 2.2.1
- **아키텍처**: MobileNetV1
- **설정값**:
  - `outputStride`: 16 (정확도와 성능의 균형)
  - `multiplier`: 0.75 (모델 크기와 성능 조절)
  - `quantBytes`: 2 (모델 압축을 위한 양자화)
  - `segmentationThreshold`: 0.7 (인체 인식 임계값)

## 인체 인식 과정

1. **카메라 입력**: 사용자의 웹캠에서 실시간 영상을 받아옵니다
2. **프레임 처리**: 각 프레임을 BodyPix 모델에 입력으로 전달합니다
3. **세그멘테이션**: 모델이 픽셀 단위로 사람인지 배경인지를 판단합니다
4. **마스크 생성**: 인체 영역에 대한 이진 마스크를 생성합니다
5. **시각화**: 인체 영역에만 바이너리 텍스트 효과를 적용합니다

## 성능 최적화

- **내부 해상도**: 'medium' 설정으로 처리 속도와 정확도의 균형 유지
- **프레임 처리**: `requestAnimationFrame`을 사용한 부드러운 애니메이션
- **캔버스 최적화**: 숨겨진 캔버스를 사용하여 픽셀 데이터 추출 최적화

## 개인정보 보호

- **로컬 처리**: 모든 AI 처리는 사용자의 기기에서 로컬로 실행됩니다
- **데이터 전송 없음**: 카메라 영상이 외부 서버로 전송되지 않습니다
- **실시간 처리**: 영상 데이터는 메모리에서만 처리되며 저장되지 않습니다

## 기술적 한계

- **성능 요구사항**: 실시간 처리를 위해 상당한 계산 자원이 필요합니다
- **브라우저 호환성**: WebGL을 지원하는 모던 브라우저에서만 동작합니다
- **조명 조건**: 조명이 부족하거나 과도할 경우 인식 정확도가 떨어질 수 있습니다
- **복잡한 배경**: 배경이 복잡하거나 사람과 유사한 형태가 있을 경우 오인식 가능성이 있습니다

## 윤리적 고려사항

이 프로젝트는 순수한 예술적 표현을 목적으로 하며, 개인을 식별하거나 추적하는 기능은 포함되어 있지 않습니다. AI 기술은 창조적인 미디어 아트 경험을 제공하기 위한 도구로만 사용됩니다.

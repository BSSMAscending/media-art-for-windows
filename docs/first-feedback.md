# 개발 초안 피드백

## 현재 구현 평가

- 이미지 변환 결과는 직관적이고 시각적으로 완성도가 있음
- 사용자 입장에서 "재미있다"는 반응은 충분히 유도 가능

---

## 1. 개발 초안 피드백 (미디어아트)

1. **바이너리(2진법) 위주**여서 실제 이미지 처리에 수학이 사용됨을 인지하기 어려움
2. 이미지를 아스키코드나 문자로 보이게 하는 부분은 처음엔 흥미로울 수 있으나, **이미지 처리와 수학과의 연계성**을 가지기 어려움
3. 각 픽셀별로 `0~256` 또는 `0~64` 등의 숫자를 볼 수 있는 초안 형식의 구현물 필요
4. 이미지 밝기, 블러, 샤프너 등에 사용되는 **수학적 처리 기법이나 사용된 함수의 설명**과 그에 따른 이미지 내 숫자의 변화를 관찰할 수 있는 부분이 도드라졌으면 함

---

## 2. 조작 인터페이스 및 시각적 방향성

전시 콘텐츠지만 사용자가 **조절 레버(슬라이더)를 돌려가며 입자의 크기를 직접 조절**하도록 구성하면 좋겠음.

단순히 결과를 보는 구조에서 벗어나, 입력 값을 조절하며 중간 변화 과정을 단계별로 시각화하여 사용자가 **'직접 실험하는 콘텐츠'** 로 함께 제작하는 것도 좋겠음.

### 향후 과제 및 개선 방향

레버의 단계에 맞춰 픽셀이 작아지는 메인 화면 옆에, 현재 단계의 **수학적 기법(행렬, 이진법, 사용된 함수 등)** 과 숫자 데이터의 변화를 실시간으로 표출하는 **보조 UI 설계**가 필요함.

### 색상 단계별 구성안

| 단계 | 설명 | 색상 수 |
| ---- | ---- | ------- |
| 원본 | R=256 (8bit), G=256 (8bit), B=256 (8bit) | 16,777,216색 (약 16만 컬러) |
| 흑백 | 2 bit | 2색 |
| 흑백 | 10진수 (0~9) | 10단계 |
| 흑백 | 256, 8bit | 256단계 |
| 컬러 | R=16 (4bit), G=16 (4bit), B=16 (4bit) | 4,096색 (4천 컬러) |
| ... | | |

> 이렇게 **색과 숫자와의 관련성**을 추가하면 좋겠음.

---

## 3. 전시물의 단조로움

현재 제작되는 전시물의 경우에는 2차원의 실루엣만 수학의 이진법으로 표현하기 때문에 전시물이 단조롭게 느껴질 수 있음.

사람의 코와 같이 입체적인 양감을 **3차원적으로 표현**할 수 있으면 전시물의 정교함을 보여줄 수 있다고 생각함.

흑백 버전의 경우는 수학적 의미를 드러내는 전시물과는 방향이 조금 다르지만, 숫자 버전과 바이너리 버전은 정교화 작업을 거친다면 의미 있는 전시물이 될 수 있을 것이라 판단됨.

### 개선 필요 사항

- **경계 구분**: 자켓과 반팔 티셔츠 간의 경계, 두 사람 사이의 경계가 모호하게 드러나서 구분할 수 있는 방법이 필요
- **정교화**: 사람의 얼굴 형상, 불분명한 손가락 등의 모습이 더 정교화되길 바람
- **배경 연출**: 전체 배경이 검정색보다는 파란색이 되거나, 영화 \<매트릭스\>와 같이 숫자가 흐르는 듯한 연출을 하는 것도 의미 있어 보임

---

## 4. 전시물 속 수학적 의미를 드러내는 것이 부족

해당 전시물로는 수학과의 연관성을 드러내는 것이 어려워보임. 추후 전시 공간에 설명이 잘 되어있는 것이 필요함.

### 전시 설명 예시

> 우리가 움직이는 모든 모습은 수학이라는 돋보기를 통해 바둑판 모양의 행렬 위에 놓인 숫자 데이터로 바뀌어 컴퓨터 속으로 들어갑니다. 카메라가 포착한 장면을 아주 작은 칸들로 나눈 뒤, 각 칸의 밝기 변화를 계산하여 내 몸의 테두리를 찾아내는 것이 바로 수학의 힘입니다. 이렇게 찾아낸 형상을 **'내 몸이 있는 곳은 1, 없는 곳은 0'** 이라는 이진법 규칙으로 약속하면, 복잡한 세상의 움직임도 컴퓨터가 이해할 수 있는 정교한 정보로 변신하게 됩니다. 결국 우리가 보는 마법 같은 반응형 프로그램은 수만 개의 숫자가 수학적 규칙에 따라 일사불란하게 움직인 결과입니다.

---

## 5. (제안) 제작 과정 중 추가 연출 요소

이번 전시물 제작은 아니더라도, 해당 전시물 프로그램에서 **하트 모양을 하면 카메라가 모양을 인식해 하트가 연출**되는 등의 아이디어도 고려해보면 어떨까 싶음.
